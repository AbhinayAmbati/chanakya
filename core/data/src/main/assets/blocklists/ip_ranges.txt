# Chanakya - DNS bypass prevention (IP-level)
#
# Public DNS resolvers, in CIDR notation. Blocking these at the IP layer stops apps
# from bypassing DNS filtering through DNS-over-HTTPS or a hardcoded resolver: their
# lookups fail and fall back to the system resolver, which Chanakya filters.
#
# The device's own DNS servers are always excluded at runtime, so this can never
# break the resolution the device actually relies on.
#
# Well-known, tightly-scoped addresses only - broad ranges are deliberately avoided
# because blocking an IP range can affect unrelated services that share it.
